## 地图 Key

页面使用腾讯位置服务 JavaScript GL（`map.qq.com`）作为底图，本地预览走 WorkBuddy 代理，
线上需要自备一个免费 Key：

1. 到 https://lbs.qq.com/dev/console/application/mine 注册并创建应用，复制 Key；
2. 在该 Key 的「域名白名单」中填入 `lyonliqima.github.io`；
3. 打开页面时会自动弹出输入框，粘贴一次即保存在浏览器 localStorage；
   也可以直接用 `https://lyonliqima.github.io/qinghai-gansu-route-map/?key=你的Key` 打开。
