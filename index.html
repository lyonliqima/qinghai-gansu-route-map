青甘自驾 · 9/22–9/27

西宁曹家堡机场出发，嘉峪关机场飞走，全程约 2100km。地图共 41 个点，点击标记看说明；点击某一天可高亮当天路线。

蓝色大点（带序号）= 住宿地
橙色 = 行程已定的点
紫色 = 可选加的点
绿色 = 博物馆 / 文化馆

点位为 GCJ-02 近似坐标，用于行程示意；实际导航请以地图 App 搜索的景区大门为准。底图为腾讯地图，国界与行政区划按国家标准绘制。

需要腾讯地图 Key 才能显示底图

本页在 GitHub Pages 上运行时，地图底图要走腾讯位置服务官方接口，需要一个免费 Key：
1. 打开 lbs.qq.com 注册并创建应用，拿到 Key；
2. 在该 Key 的「域名白名单」里填上 lyonliqima.github.io；
3. Key 会保存在这台设备的浏览器里，之后打开就不用再填。
也可以直接在网址后面加 ?key=你的Key 打开。
